# Тексты карточки RuStore

## Название

Pulse: музыкальный плеер

## Краткое описание

Стильный офлайн-плеер: поиск, плейлисты, эквалайзер и виджет.

## Полное описание

Pulse — удобный музыкальный плеер для аудиофайлов на вашем Android-устройстве. Он быстро находит локальную музыку, работает без регистрации и продолжает воспроизведение в фоне.

Возможности:

- поиск по названию, исполнителю, альбому и папке;
- медиатека по трекам, исполнителям, альбомам и папкам;
- избранное и собственные плейлисты;
- настраиваемая очередь воспроизведения;
- эквалайзер с готовыми пресетами;
- виджет для главного экрана;
- управление из уведомления и с экрана блокировки;
- перемешивание, повтор и таймер сна;
- восстановление очереди и позиции после перезапуска.

Музыкальные файлы и плейлисты остаются на устройстве. Pulse распространяется бесплатно и содержит компактную рекламу.
