# Политика конфиденциальности Pulse Player

Дата вступления в силу: 12 октября 2026 года.

Pulse Player — офлайн-плеер для воспроизведения аудиофайлов, находящихся на устройстве пользователя. Используя приложение, пользователь соглашается с условиями настоящей политики.

## Какие данные обрабатывает приложение

Для поиска и воспроизведения музыки Pulse Player запрашивает системное разрешение на доступ к аудиофайлам. Названия треков, исполнители, альбомы, пути к файлам, избранное, плейлисты, очередь и настройки эквалайзера обрабатываются и хранятся только на устройстве. Разработчик не получает и не загружает эти сведения на собственный сервер.

Для показа рекламы приложение использует Yandex Mobile Ads SDK. Рекламный сервис может автоматически обрабатывать технические сведения, включая рекламный идентификатор устройства, IP-адрес, сведения об устройстве и операционной системе, приблизительное местоположение на основе сети, а также данные о показах и взаимодействии с рекламой. Эти данные используются для показа, ограничения частоты, измерения эффективности и защиты от недействительного трафика.

Приложение не требует регистрации и не запрашивает имя, номер телефона, адрес электронной почты или платёжные данные.

## Правовые основания и сроки хранения

Локальные данные обрабатываются по инициативе пользователя для выполнения функций плеера и хранятся до удаления данных приложения или его удаления с устройства. Обработка данных рекламным сервисом осуществляется в соответствии с применимым законодательством и документами Яндекса. Сроки хранения и порядок удаления таких данных определяются рекламным сервисом.

При первом запуске пользователь выбирает, разрешать ли персонализацию рекламы. Выбор передаётся рекламному SDK при каждом запуске и может быть изменён в разделе «О приложении» → «Настройки рекламы». Пользователь также может сбросить или ограничить использование рекламного идентификатора в настройках Android, удалить локальные данные через системные настройки приложения либо удалить Pulse Player.

## Передача третьим лицам

Разработчик не продаёт пользовательские данные. Единственный внешний компонент, который может получать технические данные, — Yandex Mobile Ads SDK. Политика конфиденциальности Яндекса: <https://yandex.ru/legal/confidential/>.

## Дети

Pulse Player не предназначен специально для детей и не собирает осознанно данные о возрасте пользователя. Реклама должна настраиваться разработчиком с учётом выбранной возрастной категории приложения и требований рекламной сети.

## Изменения политики

Актуальная версия политики публикуется по этому адресу. При существенных изменениях дата вступления в силу будет обновлена.

## Контакты

По вопросам конфиденциальности и удаления данных можно обратиться к разработчику через GitHub: <https://github.com/maxx52/PulsePlayer/issues>.
