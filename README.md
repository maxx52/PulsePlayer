# Pulse Player 0.3

Стильный офлайн-плеер для локальной музыки на Android. Приложение читает аудиофайлы через системный `MediaStore` и не отправляет медиатеку в интернет.

## Что уже работает

- поиск по названию, исполнителю и альбому;
- воспроизведение локальных треков и очередь;
- пауза, перемотка, предыдущий/следующий трек;
- перемешивание и режимы повтора;
- фоновое воспроизведение через Media3;
- системное уведомление и управление с экрана блокировки;
- обложки альбомов из медиатеки телефона;
- избранные треки;
- создание и удаление плейлистов;
- добавление треков в плейлисты и удаление из них;
- локальное хранение настроек через DataStore;
- просмотр медиатеки по трекам, исполнителям и альбомам;
- редактируемая очередь: воспроизведение следующим, добавление в конец,
  изменение порядка и удаление;
- восстановление очереди, последнего трека, позиции, повтора и перемешивания;
- таймер сна на 15, 30, 45 или 60 минут;
- просмотр медиатеки по папкам с поддержкой Android 8+;
- сортировка по названию, исполнителю, дате добавления и длительности;
- сортировка по возрастанию и убыванию;
- поиск также учитывает путь к папке.

## Технологии

- Kotlin и Jetpack Compose;
- Material 3;
- AndroidX Media3 / ExoPlayer;
- MediaSessionService;
- MediaStore;
- Preferences DataStore.

## Запуск

1. Откройте папку `PulsePlayer` в актуальной Android Studio.
2. Дождитесь окончания Gradle Sync.
3. Установите Android SDK 37, если Android Studio предложит это сделать.
4. Запустите приложение на устройстве с Android 8.0 или новее.
5. При первом запуске разрешите доступ к аудиофайлам.

Для проверки медиатеки лучше использовать реальный телефон: эмулятор обычно не содержит музыкальных файлов.

## Структура

- `data/MediaStoreMusicRepository.kt` — сканирование музыки, папок и даты добавления;
- `data/MusicPreferences.kt` — избранное, плейлисты и сохранение состояния плеера;
- `playback/PlaybackService.kt` — фоновый плеер и системная медиасессия;
- `MainViewModel.kt` — состояние приложения и управление воспроизведением;
- `ui/PulseApp.kt` — экраны медиатеки, очереди и плеера;
- `ui/theme/PulseTheme.kt` — фирменная тёмная тема.
